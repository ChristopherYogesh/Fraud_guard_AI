# Fraud Guard AI

This repository contains the complete Fraud Guard AI project: the Flask application, training scripts, trained model weights, and YOLO-format dataset.

## Project guide

See [the application README](fraud_guard_ai/README.md) for the system overview, setup instructions, and usage details.

## Repository layout

- `fraud_guard_ai/`: Flask application, tests, training code, and trained checkpoints
- `dataset/`: YOLO-format training, validation, and test data
- `weights/`, `runs/`: model and evaluation artifacts from the project workspace

The local virtual environment, credentials, runtime database, and user-uploaded media are excluded from version control.
